# 1.Purpose

The Parking Garage Management (PGM) System is designed to manage and monitor parking garages. It automatically records each vehicle’s license plate, entry time, exit time, and calculates the appropriate parking fees. Operators can view records and get reports. By automating tracking and billing, the system reduces errors and increases efficiency for parking garages

# Requirements

- Java 8+
- Eclipse IDE (or any IDE that can run Java projects)

# How to Run the Program

### 1. Import the project into Eclipse

- Open Eclipse

- Go to File → Import → Existing Projects into Workspace

- Select the project folder

- Finish

### 2. Run the Server

- In the src folder, locate PGMS.java

- Right-click → Run As → Java Application

- This starts the server that handles garage operations and Owner GUI that has total control of all garages

### 3. Run the Client

- In the src folder, locate ParkingGarageClient.java

- Right-click → Run As → Java Application

- This starts the client, Driver Exit GUI and Operator GUI
